Arquitectura del cliente

  • Este proyecto no utiliza base de datos ni migraciones.
  • La sesión se almacena en una cookie firmada, no en SQLite.
  • No se utiliza el admin de Django ni formularios automáticos.
  • Las pantallas consumen la API mediante JWT con el encabezado Authorization.
  • Los datos de usuarios y permisos viven únicamente en el Proyecto 1.
