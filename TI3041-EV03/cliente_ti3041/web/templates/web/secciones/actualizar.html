Cambiar contraseña

La operación se envía a PUT /actualizar/ usando el JWT.

{% if usuario.is_staff %} Como administrador puede cambiar la contraseña de otro usuario. {% else %} Solo puede cambiar su propia contraseña. {% endif %}
Obligatoria para cambiar su propia contraseña. Un administrador puede omitirla al cambiar la de otro usuario.
Mínimo 8 caracteres, no numérica ni demasiado común.

Seguridad

  • La contraseña actual se verifica antes de aplicar el cambio.
  • La nueva contraseña pasa por los validadores configurados en la API.
  • Un usuario normal no puede modificar la contraseña de otro.
  • El cambio se guarda en SQLite mediante el modelo Usuario.
Endpoint utilizado PUT /api/actualizar/
